# Organización Web

> Para ejecutar, asegúrate de tener NodeJS y PNPM instalados y en el PATH.

Dentro de la carpeta, ejecuta:
```bash
pnpm i

```

Una vez se haya instalado todo, el entorno de ejecución en desarrollo se monta ejecutando:
```bash
node --run dev
```

Para producción (generación de estáticos):
```bash
node --run build
```

# Generación de ejemplos
Para generar un excel input de ejemplo, ejecuta:
```bash
node src/generate.js
```
